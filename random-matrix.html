Wigner Semicircle

随机对称矩阵的单个元素没有结构，但大量本征值会收敛到确定的半圆谱密度。这是“微观随机 → 宏观普适”的经典例子。

A=Aᵀ, Aᵢⱼ∼N(0,1/N)
ρ(λ)=√(4−λ²)/(2π)
GOE-like ensemble
黑柱：数值本征值 histogram；红线：理论 Wigner semicircle。N 和样本数增大后，经验谱密度会逐渐贴近理论曲线。

Matrix size N28

Interpretation

  • 本征值之间不是独立随机数，会出现强烈的 level repulsion。
  • 适当缩放后，谱宽不会随 N 发散，而趋向半圆分布。
  • 随机矩阵理论广泛出现在量子混沌、核物理、复杂网络和神经网络谱分析中。
